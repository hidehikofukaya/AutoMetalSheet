# AutoMetalSheet 学習資料

`archi.md`（GHMR: Guarded Hierarchical Mesh Refiner アーキテクチャ）を自力で理解するための学習資料群。
出典の優先順位は `archi.md §0-§0I`（規範）> `AGENTS.md`（決定ログ）> `archi_audit.md`（監査）> `CLAUDE.md`（履歴）。
本資料はすべて非規範（教材）であり、内容に矛盾があれば常に `archi.md` を正とする。

## 構成方針

- カテゴリ（A〜F）ごとにサブフォルダを作成する。
- 各カテゴリの項目は1項目1ファイルとし、必ず以下を含める。
  1. 数学的記述（定義・導出。可能な限り厳密に）
  2. Mermaid図による視覚表現
  3. 本プロジェクトの実コードとの対応関係（未実装の場合はその旨を明記）
  4. `archi.md` との接続（その概念がなぜ GHMR 設計上必要か）
  5. 自己チェック問題
