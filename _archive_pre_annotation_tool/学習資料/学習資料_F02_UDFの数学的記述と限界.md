> 本資料の作成動機: 「UDFは距離場同士がフィードバックしあって異常値を除去する仕組みがなければ精緻化は不可能ではないか」というユーザー仮説の検証

## 0. 結論を先に

このPoCがTD-16(ゴーストメッシュ)・「虫食い」で苦しんでいる症状は、**実装の不備ではなく、UDFという数学的表現そのものに内在する限界**です。具体的には「中立面の境界(切断端)では、UDFという関数自体が数学的に微分不可能な"キンク"を持つ」という事実が根本原因であり、ニューラルネットがどれだけ賢くなっても、この特異点を**滑らかな関数で完璧には近似できません**(§3, §4)。

ユーザーの「距離場同士がフィードバックしあって異常値を除去する機構が必要」という直感は、**半分正しく、半分は罠です**。

- **正しい部分**: 実際に「予測値同士を突き合わせて整合性を取る」手法は文献に複数存在し(CAP-UDF, MeshUDF)、このPoC自身もR7-11/R7-12で「予測UDF値を、実際の入力点群という"外部情報"と突き合わせて遠い点を捨てる」という、まさにフィードバック的なゲート機構を実装し、大幅な改善(mean誤差53.83mm→8.57mm)を達成しています(§6, §7)。
- **罠の部分**: このPoCは既に一度「フィードバック機構」そのものを試して**失敗**しています。Round 8のDeep Ensembles実験(5つの独立モデルの予測ばらつきを使う)です。5モデルの予測は系統的に同じ間違え方をしたため、ばらつき(disagreement)は異常値検出の役に立ちませんでした(相関係数0.17)。**「予測同士をフィードバックさせる」だけでは不十分で、フィードバックの片方が"モデルの予測"ではなく"独立した外部の実測情報"でなければ機能しない**、というのが実験的にも理論的にも裏付けられた結論です(§7)。

以下、数学的基礎から順に説明します。

---

## 1. UDFの数学的定義

ある集合(面)`S ⊂ R³`に対して、符号なし距離関数(Unsigned Distance Function)は次のように定義されます。

```
U(x) = min_{p∈S} ‖x − p‖₂
```

つまり「点`x`から集合`S`上の最も近い点までのユークリッド距離」です。ニューラルネットによるUDF近似を最初に広めたのは Chibane et al., *"Neural Unsigned Distance Fields for Implicit Function Learning"* (NDF, NeurIPS 2020, [arXiv:2010.13938](https://arxiv.org/abs/2010.13938)) で、本PoCのStage B(VecSet Autoencoder)が学習しているのもこの`U(x)`の近似です。

### 基本性質

| 性質 | 内容 | 根拠 |
|---|---|---|
| 1-Lipschitz連続 | `\|U(x)−U(y)\| ≤ ‖x−y‖` が常に成立 | 三角不等式から直接導かれる(`S`上の任意の点`p`について `\|‖x−p‖−‖y−p‖\| ≤ ‖x−y‖`、これを`min`で取っても保存される) |
| 非負・ゼロ集合 | `U(x) ≥ 0`、`S`が閉集合なら`U(x)=0 ⟺ x∈S` | 距離の定義そのものから自明、`S`の閉性が`min`の到達可能性を保証 |
| Eikonal方程式 | ほとんど至るところ(特異点を除き) `‖∇U(x)‖ = 1` | Crandall & Lions, *"Viscosity Solutions of Hamilton-Jacobi Equations"*, Trans. AMS 277 (1983) — 距離関数がこの偏微分方程式の(一意な)粘性解であることを示した基礎文献 |
| 勾配の向き | `U`が微分可能な点`x`では `∇U(x) = (x − p*)/‖x − p*‖`(`p*`は唯一の最近傍点) | 微分可能 ⟺ 最近傍点が一意、というのが次節のcut locusの裏返しの定義 |

最後の「勾配の向き」の性質は、このPoCの`gradient_project()`(中立面投影・Stage Cのゼロレベル集合への射影の両方で使用)が直接利用している事実です。`q = p − U(p)·∇U(p)`という更新式は、まさに「勾配と逆方向に距離分だけ動けば最近傍点に到達する」という上記の性質そのものです。

## 2. なぜ中立面にはSDFではなくUDFが必要なのか

SDF(符号付き距離場)は`U(x)`に「内側か外側か」の符号を追加したものです。これが成立するには、`S`が**閉じた・向き付け可能な・水密(watertight)な多様体**であり、空間を「内側」と「外側」に矛盾なく分割できる必要があります。

中立面(板厚の中心を通る仮想的な面)は厚みゼロの**開いた2次元多様体**であり、内側・外側という概念自体が存在しません。これは本プロジェクトのR6-01(CLAUDE.md §13)で既に確定している判断ですが、文献的にも同じ理由でUDFが採用されています。NDF論文自身が「壁・衣服・内部構造を持つ車など、閉じていない実物体を表現するためにSDFの限界を超える」ことを動機として明言しており、衣服復元の後続研究(例: garment reconstruction系のUDF論文)も「SDFで表現するには水密な殻として無理に閉じる必要があり、それがモデリング精度を損なう」と同じ論理を繰り返しています。つまり「中立面はSDFが定義不能だからUDFを使う」というこのPoCの選択は、衣服・薄殻構造復元という独立した研究分野でも同じ理由で繰り返し採用されている、理論的に妥当な選択だということです。

## 3. Cut locus(特異点群)と微分不可能性

ここがTD-16の根本原因に直結する、最も重要な数学的事実です。

### 定義

集合`S`の **cut locus**(切断軌跡。文脈によっては medial axis = 中心軸とも呼ばれる)とは、「`S`上の最近傍点が一意に定まらない点の集合」です。すなわち、ある点`x`について、`S`上に**2つ以上**の異なる点`p₁ ≠ p₂`が存在し、両方とも`x`からの最短距離を達成する(`‖x−p₁‖ = ‖x−p₂‖ = U(x)`)とき、`x`はcut locus上にあります。

これは決して特殊なPoCの問題ではなく、一般の距離幾何学における古典的な概念です(Federer, *"Curvature Measures"*, Trans. AMS 93 (1959) が起源で、"reach"の概念とともに定式化)。

### なぜcut locus上で微分不可能なのか

`x`がcut locus上にあるとき、`p₁`方向への勾配`(x−p₁)/‖x−p₁‖`と`p₂`方向への勾配`(x−p₂)/‖x−p₂‖`は一般に**異なるベクトル**です。`U`の勾配はこの2つの「綱引き」のどちらか一方には決まらず、関数`U`は`|x|`が原点で持つような**キンク(角)**を持ちます。つまり`U`はcut locus上で連続(C⁰)ではあるが微分不可能(C¹ではない)です。

### Viscosity solution(粘性解)という考え方

「`‖∇U‖=1`を満たす滑らかな(至るところ微分可能な)関数」は、cut locusのキンクのせいで**大域的には存在し得ません**。そこでEikonal方程式の「解」として、古典的な微分可能性を要求しない、より弱い概念である**粘性解(viscosity solution)**が導入されます。Crandall-Lions(1983)が確立したこの枠組みでは、`U`は微分不可能な点でも(劣微分・優微分を使った不等式の意味で)方程式を満たす、一意で安定した「正しい」解として特徴づけられます。距離関数がEikonal方程式の粘性解である、というのは応用数学では標準的な事実です。

**実用上の意味**: ニューラルネットは滑らかな関数の族(MLP)で`U`を近似しようとしますが、cut locus上の真のキンクは原理的に滑らかな関数では表現できません。ネットワークはキンクの周辺をぼかして近似するしかなく、このぼかしが「予測UDFの局所的な誤較正」という形で現れます。これがTD-16のゴーストメッシュ・「虫食い」の数学的な源流です。

## 4. 開いた境界(切断端)に特有のcut locus問題

ここがこのPoCの中立面に特有の、特に厳しい事実です。

通常の**閉じたソリッド**(SDFが定義できるケース)では、cut locusは一般にソリッドの内部の奥深くに位置し、表面のすぐ近くではSDFは滑らかです(例えば薄い直方体なら、cut locusは中心線上にしか現れません)。だからこそSDFベースのMarching Cubesは表面近傍でよく機能します。

ところが**開いた面の境界(切断端)** では事情が異なります。境界の外側(面が存在しない側)に出ると、その点の「最近傍点」は境界曲線(切断エッジ)上のどこか1点になりますが、境界曲線が曲がっていれば、境界に沿って移動するにつれてこの最近傍点は連続的に変化し、ときに複数の境界点が等距離で「綱引き」を起こします。これは2次元多角形の外側にできるmedial axisが、まさに多角形の頂点・辺から生成されるのと同じ構造です。

この資料の調査で見つかった直接の文献的裏付けはまだ存在しませんが(該当する論文は未発見)、以下は幾何学的に妥当な推論として明記します:

> **境界曲線そのものが、表面のすぐ外側にcut locus構造を生み出す"発生源"として働く。** 閉じたソリッドのcut locusが内部の奥深くに安全に押し込められているのとは対照的に、開いた境界のcut locusは表面のすぐ近く、場合によっては境界上そのものに張り付く形で発生する。

これは本プロジェクトの実測結果と整合します。TD-16の根本原因分析(CLAUDE.md §14)では、「悪い点」(Recon→GT距離が大きい点)とGT境界エッジまでの距離の相関係数が**1.0**という、ほぼ完全な相関が確認されています。これはまさに「境界=cut locusの発生源」という上記の推論が実証されたケースと言えます。

また、DUDF論文(Fainstein et al., CVPR 2024, [arXiv:2402.08876](https://arxiv.org/abs/2402.08876))も一般論として「UDFはゼロレベル集合(=表面そのもの)で非微分可能であり、これが距離・勾配の重大な誤差、ひいては断片化・不連続な表面を引き起こす」と明言しており、SDFと異なりUDFの特異点が**表面のすぐそば**に存在するという構図そのものを裏付けています。

## 5. ニューラルネットによるUDF近似の既知の失敗モード

### 5.1 Spectral bias(低周波優先学習)との相互作用

Rahaman et al. (ICML 2019, [arXiv:1806.08734](https://arxiv.org/abs/1806.08734)) は、勾配降下法で学習するMLPが低周波成分を高周波成分よりも著しく速く学習する("spectral bias")ことを示しました。Tancik et al. (NeurIPS 2020, [arXiv:2006.10739](https://arxiv.org/abs/2006.10739)) はNTK理論を用い、座標を生のまま入力するMLPはNTKが高周波で急減衰するため高周波内容を実用的な時間で学習できないこと、Fourier特徴埋め込みがNTKを定常かつ調整可能な帯域を持つカーネルに変形することを示しました。

ただしFourier特徴は**帯域全体を底上げするだけ**で、ネットワークが「1点に集中して無限に近い局所周波数」を表現できるようにするものではありません。cut locusのキンクはまさにそうした局所的・無限周波数的な特異点であり、Fourier特徴だけでは原理的に解消しきれないと考えられます。

これは本PoCの実験結果とも整合します。R7-05でFourier特徴を導入した結果、near_mae(表面近傍の汎用的な予測精度)は0.42mm→0.0056mmへと劇的に改善しましたが、これは「大域的な低周波偏重バイアス」の解消であって、TD-16の局所的な境界オーバーシュートは別問題として残り続けました。

### 5.2 「ゴースト面・スプリアス面」は文献でも広く報告されている既知の症状

- Zhang et al., *"Surface Extraction from Neural Unsigned Distance Fields"* (ICCV 2023, [arXiv:2309.08878](https://arxiv.org/abs/2309.08878)、本PoCのTD-16調査で既出): 「ニューラルUDFはゼロレベル集合とそのcut locus付近でより大きな誤差を持つ傾向がある」と明記。根本原因を「(1) UDFは符号変化を持たない、(2) 学習されたUDFには大きな近似誤差がある」の2点に整理。
- MeshUDF(Guillard et al., ECCV 2022, [arXiv:2111.14549](https://arxiv.org/abs/2111.14549)): 「境界や鋭い角の近くにスプリアスな面が生じる」と自ら認めている。
- DEUDF([arXiv:2406.00346](https://arxiv.org/abs/2406.00346)): UDFの病理を「ゼロレベル集合での非微分可能性、正確なゼロ値達成の困難さ、多数の局所最小値、ゼロレベル集合付近での勾配消失・振動」として包括的にカタログ化。

### 5.3 代替アプローチ(符号を諦めずに開いた面を扱う方法)

| 手法 | 出典 | 機構 | 解決する問題 | 新たな問題 |
|---|---|---|---|---|
| NDF | NeurIPS 2020 | UDF回帰 + Ball-Pivoting後処理 | 開いた面の表現 | Marching Cubes不可、後処理が遅く穴だらけ(GIFS比 2593秒 vs 53秒) |
| GIFS | CVPR 2022 | 点**対**ごとに「間に面があるか」を二値分類 | 連続スカラー距離を回帰しないため非微分可能性を損失に持ち込まない | 八分木1セルあたり最大256通りの二値ラベル組合せでリアルタイム不可 |
| 3PSDF | CVPR 2022 | 内/外に加え第3のNULLラベルを導入 | Marching Cubes互換のまま開いた面を表現 | NULL領域の境界処理に新たな調整が必要 |
| DUDF | CVPR 2024 | 双曲スケーリング`t=d·tanh(α·d)`で表面上の勾配を滑らかに消失させる | cut locus特異性を**学習目的関数の段階で**解消(後処理ではない) | GT符号なし距離の教師あり学習が必要、表面付近がやや厚く膨張、3回のネットワーク評価+曲率方向のHessian計算でコスト増 |

## 6. 「距離場同士のフィードバック」は文献に実在するか

ユーザーの仮説を検証するため、「予測値が互いに整合性を取り合う」機構を持つ手法を具体的に調査しました。

| 手法 | フィードバック機構の実体 | 対象とする異常 | 残存する限界 |
|---|---|---|---|
| **MeshUDF** (ECCV 2022) | 隣接セルの勾配同士の内積`g₁·gᵢ`で擬似符号を決め、未確定の頂点は**既に確定した近傍からの投票**をBFSで集めて解決する。文字通り「隣の予測が自分の予測を訂正する」仕組み | Marching Cubes用の符号付け不能問題 | 自身の論文で「境界や交差部近くにスプリアス面が生じる」と認めている。本PoCの症状そのものが未解決として残る |
| **CAP-UDF** (NeurIPS 2022 / TPAMI 2024) | クエリ点を勾配方向に「引き寄せ」、引き寄せた**後**の点を新たな教師信号として使う反復ループ。「整合性(consistency)」とは、引き寄せ前後で矛盾しない教師信号を動的に作ることを指す | 単純なChamfer損失が収束しない・歪む問題 | 後続研究(DualMesh-UDF, ICCV 2023)が「CAP-UDFは概ね正確だが、望まれない穴を作る傾向がある」と明記。本PoCの「虫食い」と構造的に同型の症状 |
| **NeuralUDF** (CVPR 2023) | 複数視点間の整合性ではなく、**1本のレイ内**の複数交差を解決する可視性指標のみ。視点間・点間のフィードバックは存在しない | マルチビュー体積レンダリングへのUDF適用 | 該当なし(そもそも異常値除去を目的にしていない) |
| **Neural Dual Contouring** | CNNの受容野を通じた暗黙的な近傍共有のみで、明示的な投票・整合性強制ステップは無い | Marching Cubesの水密性要求の回避 | 論文自身が非多様体メッシュの発生を認め、後処理での切断が必要と明記 |
| **LevelSetUDF** (ICCV 2023) | ゼロレベル集合以外の**滑らかな**他のレベル集合上の点を、勾配整合を使ってゼロレベル集合へ投影し直す。異なる点の予測同士が直接フィードバックし合う | cut locus付近の不安定性そのものを標的にしている、最もユーザーの仮説に近い手法 | 本PoCでは未検証(着手候補) |
| **Neural Surface Detection for UDFs** (ECCV 2024) | **意図的に**近傍間の整合性強制を行わない設計。「特定の前提を作り込まない」ことを目的にあえて不採用とした | 設計上の代替案 | 自ら「境界エッジに残存するジャギーがある」と認めており、整合性強制だけでは不十分という直接的な反証になっている |

### 重要な観察: 「整合性機構」は存在するが、どれもTD-16(境界オーバーシュート)を主問題として名指ししていない

MeshUDFもCAP-UDFも、整合性/フィードバック機構を持ちながら、**いずれも境界付近のアーティファクトが未解決のまま残っている**と自ら報告しています。これは「フィードバック機構さえあれば精緻化できる」というユーザー仮説に対する重要な反例です。フィードバック機構は「一般的な滑らかさ・符号の矛盾」は解消できても、cut locusという数学的な特異点そのものを消し去ることはできていません。

一方、**DUDF**は逆に、フィードバック機構を一切持たず(単一点ごとの関数再定義のみ)、cut locusの根本(勾配が表面でゼロに収束しない)を学習目的関数のレベルで直接修正するアプローチです。これは「点同士のフィードバック」とは全く異なる発想であり、むしろこのPoCのTD-16によりダイレクトに効く可能性があります。

## 7. このPoC自身の実験が示した教訓: フィードバックは「外部の独立情報」とでなければ機能しない

ここが、ユーザーの仮説に対する最も具体的で説得力のある答えです。このPoCは実際に「予測同士のフィードバック」を試して**失敗した経験**(Round 8, CLAUDE.md §15)と、**成功した経験**(同じくRound 8〜10, R7-11/R7-12)の両方を持っています。

### 失敗したケース: Deep Ensembles(予測同士だけのフィードバック)

5つの独立したモデル(同一アーキテクチャ・同一損失関数・乱数シードのみ異なる)を学習し、予測のばらつき(disagreement)を異常検知に使えるか検証しました。結果は次の通りです。

- 既知の最悪30頂点(平均誤差245mm)でのensemble disagreementは2.136mm — 全グリッド平均の2.156mmとほぼ同じで、**異常値とそうでない点を全く区別できなかった**
- disagreementと真の誤差の相関係数は**0.1671**(ほぼ無相関)
- disagreement自体をゲートとして使うと、むしろベースラインより悪化した(max誤差が244.77mm→257.36mm)

**なぜ失敗したか**: 5つのモデルはすべて同じ損失関数設計(truncated-distance loss、R7-03)を共有しており、これがUDFの値域に天井を作る効果を**全モデルに系統的に**もたらしていました。Deep Ensemblesが捉えられるのは「ランダムな初期化・データ順序由来のばらつき(epistemic uncertainty)」だけであり、**損失関数設計という、全モデルに共通する系統バイアス由来の誤差は原理的に捉えられません**。バイアス・バリアンス・共分散分解で言えば、

```
E_ensemble = mean(bias²) + (1/M)·mean(variance) + (1 − 1/M)·mean(covariance)
```

メンバー間の誤差が強く相関している(covarianceが大きい)場合、メンバー数`M`をいくら増やしてもこの項は消えません。「全員が同じ理由で同じように間違える」状況では、フィードバック(=disagreementの観測)自体が無意味になります。

### 成功したケース: R7-11/R7-12(予測値 vs 実測点群というフィードバック)

一方、本番採用された解決策は、**モデルの予測UDF値を、実際に入力された(実測の)点群までの距離という、モデルの外部にある独立した情報と突き合わせて**、遠すぎる候補点・頂点を機械的に除外するというものでした。

- R7-11: グリッド評価点が実際の入力点群から`input_dist_threshold_mm`(10mm)を超えて離れていれば、予測UDF値や確信度に関わらず候補から除外
- R7-12: 生成されたメッシュ頂点が、実際に使った候補点群から`prune_dist_threshold_mm`(12mm、後に20mmへ調整)を超えて離れていれば削除

結果: Recon→GT平均誤差 53.83mm→**8.57mm**(6.3倍改善)、最大誤差 244.77mm→**47.27mm**(5.2倍改善)。

### この対比から得られる一般原則

古典的なロバスト統計学にも同じ構造があります。

- **RANSAC**が機能する前提は「ノイズの乗った特徴量は、どのモデルに対しても一貫して投票しない」ことです。もし外れ値が共通の原因で同じ方向に間違える(=互いに"結託"する)なら、RANSACは自信満々に間違った答えに収束します。
- **バイラテラルフィルタ/MRFによる平滑化**が機能するのは、外部の(独立に測定された)信号にアンカーしているからです。

これらはすべて、本PoCのDeep Ensembles失敗・R7-11/R7-12成功と**全く同じ構造**を持っています。

> **「クロスチェック・フィードバック機構は、チェックし合っている当事者同士が共有していない誤差しか検出できない」**
>
> 判定基準: 疑わしい誤差の原因が、アンサンブル/フィードバック機構が実際にランダム化している軸(乱数シードなど)に乗っているか? 乗っているなら検出可能。しかし損失関数設計・アーキテクチャ・訓練データ・「この領域は滑らかなはず」といった共有された幾何学的前提など、**全メンバーに固定された軸**に誤差の原因があるなら、いくらシードを変えて再学習しても検出できません。

## 8. ユーザーの仮説に対する最終評価

> 「UDFは面までの距離場を保存するモデル」という理解について

これはほぼ正確ですが、一点だけ補足が必要です。`U(x) = min_{p∈S}‖x−p‖`という**数学的な場(関数)そのもの**は、幾何形状から一意に決まる「正解」であり、それ自体に誤差はありません(§1)。本PoCで実際に扱っているのは、この真の`U`を**ニューラルネットで近似したもの**であり、誤差・異常値はこの「近似」のステップで生じます。さらに重要なのは、真の`U`自体が境界(cut locus)で数学的に微分不可能というキンクを持っているため(§3, §4)、**たとえ理想的な学習ができたとしても、滑らかな関数で表現するモデル(MLP)は真の`U`を完璧には表現できない**という、近似誤差以前の理論的限界があるということです。

> 「距離場同士がフィードバックしあって異常値を取り除く機構などの工夫がなければ精緻化は不可能」という仮説について

**部分的に正しく、部分的に的を外しています。**

- **正しい部分**: 「何らかの追加機構なしに、ナイーブな閾値処理だけでは精緻化できない」という直感は完全に正しいです。文献(MeshUDF, CAP-UDF)でもこのPoC自身の経験(R7-11/R7-12)でも、何らかの追加機構を入れない限りcut locus由来の異常を抑制できないことは実証されています。
- **的を外している部分**: 「フィードバックの相手」が**モデル自身の別の予測**である場合(Deep Ensemblesのように)、その機構は機能しません。なぜなら全ての予測が同じ損失関数・同じアーキテクチャという共通の歪みを共有しており、互いに「結託して」同じ間違いを犯すからです。逆に、このPoCで実際に効果を上げたのは、予測値を**実測の入力点群という、モデルの外側にある独立した情報**と突き合わせるという、半分だけ「フィードバック」的な機構でした。

つまり結論としては:

**「フィードバック」という言葉が指すものを「モデル予測同士の整合性チェック」と捉えるなら、これは(Deep Ensemblesの実例が示す通り)不十分です。しかし「モデルの予測と、独立した外部情報(実測点群、あるいは幾何学的制約)との整合性チェック」と捉えるなら、これはまさに本PoCが既に効果を実証している方向性であり、さらに推し進める価値があります。**

具体的な次の一手としては、§6の比較表にある**LevelSetUDF**(滑らかな他のレベル集合上の点をゼロレベル集合に投影し直す、文字通り「点同士のフィードバック」だが、cut locus自体を標的にしている点でMeshUDF/CAP-UDFより的を絞っている)と、**DUDF**(フィードバックではなく、cut locus自体を学習目的関数のレベルで根治する設計変更)の2方向が、文献的にもこのPoCの実体験的にも最も筋が良い候補です。

## 9. 用語集

| 用語 | 意味 |
|---|---|
| UDF (Unsigned Distance Field/Function) | `U(x)=min_{p∈S}‖x−p‖`。任意の点から集合`S`への最短距離を返す関数。`S`が開いた面でも定義可能 |
| SDF (Signed Distance Field) | UDFに「内側/外側」の符号を加えたもの。`S`が閉じた水密多様体である必要がある |
| 1-Lipschitz | 関数の変化率が常に1以下であるという性質。`U`は常にこれを満たす |
| Eikonal方程式 | `‖∇U‖=1`という偏微分方程式。距離関数の基本的な性質を表す |
| Cut locus (medial axis) | `S`上の最近傍点が一意に定まらない点の集合。UDFがここで微分不可能になる |
| Viscosity solution(粘性解) | 古典的な微分可能性を要求しない、より弱い意味でPDEを満たす解の概念。Crandall-Lions (1983) が確立。距離関数はEikonal方程式の粘性解 |
| Spectral bias | ニューラルネットが低周波成分を高周波成分より速く学習する性質。cut locusのような局所的・高周波な特異点の学習を妨げる一因 |
| ゴーストメッシュ / TD-16 | cut locus付近でのUDF外挿により、本来存在しない領域に生成されてしまう余剰メッシュ |
| 虫食い | GT→Recon方向に生じる被覆穴。ゴーストメッシュ(Recon→GT方向)とは原因も対策も独立 |
| Deep Ensembles | 複数の独立学習済みモデルの予測ばらつきを不確実性指標として使う手法。本PoCでは損失関数の共有バイアスにより不採用 |
| MeshUDF | 隣接する勾配予測同士の投票でMarching Cubes用の擬似符号を決定する手法。境界付近のスプリアス面は未解決と自認 |
| CAP-UDF | クエリ点を勾配方向に引き寄せ、引き寄せ後の点を動的な教師信号とする反復学習手法。「望まれない穴」を生じると後続研究が指摘 |
| DUDF | 双曲スケーリングでcut locus特異性を学習目的関数の段階で解消する手法。フィードバック機構ではなく関数再定義によるアプローチ |
| LevelSetUDF | ゼロでない滑らかなレベル集合上の点をゼロレベル集合へ投影し直す、cut locusを直接標的にした整合性強化手法 |
