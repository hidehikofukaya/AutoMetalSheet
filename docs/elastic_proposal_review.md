# 弾性体案(3ネットワーク構成)の実現可能性評価

Date: 2026-08-27
提案者: ユーザー
評価方法: 机上検討ではなく、**提案の第3段(弾性補正)を既存 B-core 出力に
後付け適用して実測**した。学習不要、数分。

---

## 1. 提案の要約

1. **Net1**: 締結点 → ノード群 + N×N の関係行列(物理量 or 0/1・確信度)
2. **Net2**: ノード同士の位置関係を生成(部品の大枠構造)
3. **Net3**: 弾性力学的・幾何学的補正。締結点を真値に一致させつつ全ノードを再配置

## 2. 実測結果 — 第3段は「制約充足」には完璧、「精度」には無効

B-core の生成物に対し、生成されたエッジベクトルを保ちつつ FIX 頂点を真位置へ
引き寄せる線形最小二乗(Laplacian メッシュ編集と同型)を適用:

```
E = Σ_edges |(x_i - x_j) - d_ij|²  + μ Σ_anchors |x_a - t_a|²  + λ Σ_i |x_i - x_i⁰|²
```

| 指標(20部品・中央値) | 適用前 | 適用後 |
|---|---|---|
| **FIX 通過誤差** | 6.11mm | **0.00mm** |
| gen Chamfer | 41.92mm | 41.44mm(改善は 20部品中 5部品のみ) |

**判定: Net3 の価値は制約充足であって形状精度ではない。**
構造が間違っていれば、締結点に合わせて引っ張っても間違った形が移動するだけ。
実際 2部品では悪化した(20.2→23.3mm、104.7→119.5mm)。

留保: これは**学習後に後付け**した結果。微分可能なので**学習ループ内に置けば**
生成器が「緩和後に正しくなる形」を学ぶようになり、評価は変わりうる。
線形最小二乗なので勾配は素直に通る。

## 3. 各段の価値評価

| 段 | 当方の評価 | 根拠 |
|---|---|---|
| Net1: N×N 関係行列 | **高い** | 現在の失敗そのものを構造的に消す(下記 3.1) |
| Net2: 位置生成 | 既存 | B-core の geo 段/新 points 段と同じもの。新規性なし |
| Net3: 弾性補正 | **中(制約充足に限る)** | 実測で FIX 誤差 → 0.00mm。精度改善は無し |

### 3.1 Net1 が効く理由(実測済みの失敗と噛み合う)

B-core は**生成エッジの 34% が存在しない頂点を参照して破棄**されている
(トポロジ妥当率 63.1%)。ポインタ参照方式は「無効な参照」という失敗モードを
構造的に許してしまう。**N×N 隣接行列では、生きたノード対の間の要素は常に有効**で、
この失敗モードが定義上存在しない。DiGress / GDSS など graph diffusion の標準形でもある。

## 4. 設計上の注意(採用するなら必須)

1. **N=1000 は破綻する**。10⁶ 要素の生成対象を 2,300 サンプルで学習するのは不可能。
   実データは頂点最大 148 なので **N=160 が適正**(行列 25,600 要素)。
   提案の 1000 は 40 倍過剰。
2. **単純な隣接行列ではエッジ型を表せない**。LINE/ARC/CIRCLE/CIRCLE_C の区別と、
   ARC の中間点参照が失われる。→ **多チャンネル化 N×N×型**(DiGress 方式)が必要。
3. **行列の2案は択一でなく統合すべき**。Net3 が緩和するには**自然長**が要る。
   0/1 だけでは Net3 に緩和先が無く、Net2 が全部の仕事を負う。
   → 推奨: **接続確信度 × エッジ型 × 自然長**の多チャンネル。
4. **3段カスケードは露出バイアスを増幅する**。2段でも実害を計測済み
   (G-AGF の geo 段は GT 骨格で学習し生成骨格を見て過学習: train 0.51 / val 1.35)。
   → Net3 を微分可能層として **Net2 と同時学習**すれば回避できる。これが本命。
5. **「弾性力学」と呼ぶのは過大**。中立面ワイヤーは物理的な弾性体ではなく、
   ばね状エネルギーは幾何正則化に過ぎない。板金の物理(曲げ剛性・可展性)を
   本気で入れるなら別物の研究になる。まずはばねで正しい。

## 5. E2E 原則との整合

**抵触しない。** 弾性緩和層は線形最小二乗であり微分可能で、学習ループに組み込める。
手書きの形状ルールは一つも無く、畳み込みが並進等変性の事前分布であるのと同じ意味で
**「滑らかさ・制約充足の事前分布をアーキテクチャに埋め込む」**もの。
ユーザーが退けた「決定論的エンジン」= 形状ごとの場合分けルールとは別種。

## 6. 結論と採用方針

**別系統として3ネット構成を作るのではなく、良い部分を現行 plan_g に統合する。**

- **採用済み(2026-08-27 実装)**: Net3 の弾性緩和を `relax_q()` として decode 後に
  適用。加えて `force_anchor_incidence()` で「アンカーを最低1本のエッジが参照する」
  文法制約を追加した。両者で **FIX 誤差 9.4mm → 0.60mm**
  (残差はポリライン化の 2mm 刻みによる離散化)。
- **次点候補**: Net1 の N×N 多チャンネル隣接行列。現在は points→edges 順序変更と
  相対幾何 attention で同じ失敗を狙っており、その効果を測ってから採否を決める。
  効果が不十分なら N×N へ移行する価値がある。
- **不採用**: Net2 は既存段と同一。3段カスケードも露出バイアスの理由で採らない。
