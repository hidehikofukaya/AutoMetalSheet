# 18. CATIAのエッジ分割を教師にする — 設計提案

Date: 2026-08-31
発端: ユーザーの指摘「CATIA上では座面付近の円弧は2つの円弧で、基準面の曲げは1つの円弧で
表現されていた。CATIAのエッジの分け方は1つの合理性であり、汎用的に模倣させてはどうか」。

**結論: 指摘は測定で裏付けられた。現在の教師はCATIAの頂点構造を捨てて作り直しており、
外形の残課題(長辺上の角の揺れ=余剰回転+30°)の根はそこにある。**

---

## 18.0 現状の抽出は何をしているか

抽出は2段になっている:

1. `wireframe_app` → `runs/wtok_synth/wireframes/*.json`
   **B-repエッジをそのまま**保持(エッジごとに polyline、フル精度)。**CATIAの頂点構造はここまで生きている。**
2. `wtok/convert.py` → `runs/wtok_synth/parts/*.json`(現在の教師)
   エッジ列を**溶接して1本のチェーンに繋ぎ直し、0.35mm許容差で再帰的にLINE/ARC分割**。
   **分割点はフィット都合で置かれ、CATIAの頂点は消える。**

## 18.1 測定(60部品)

| 問い | 測定 | 結果 |
|---|---|---|
| CATIAの頂点と再当てはめの角は一致するか | 再当てはめ角 → 最近傍CATIA頂点距離 | **中央値1.89mm、62%が1mm超**。エッジ数は近い(16対17)が、**置き場所が違う** |
| 生のCATIA外形の接合はどれだけ滑らかか | エッジ端の接線角(生polyline、〜2mmスパン) | **G1(<3°) 10.7% / 3〜15° 82.1% / 真の角(≥15°) 7.2%** |
| 量子化後の教師の接合 | 同、`parts` の角 | ほぼ全てが角に見える(接線連続 0%) |

**読み**: CATIAの外形は3Dでは大部分が滑らかに繋がる(折り部を横切る所は円筒面に接して曲がる)。
真の角は1部品に1〜2個しかない。現在の教師は、その滑らかな連なりを0.35mmの弦で折り、
**「本当は存在しない角」を辺の途中に発明**している。モデルはそれを忠実に学び、
角の位置が部品ごとに恣意的なぶん**揺れる** — これが余剰回転 +30° の正体で、
学習を600エポックに伸ばすと位置は0.5mm改善するのに揺れが30°悪化した(KB 17.5)こととも整合する。
KB 16.2 の「接線連続の弧は15%しかない」も、再当てはめが接線を壊した結果だった。

座面の「2つの円弧」もCATIAの頂点(分割点)であり、現在の教師では消えたり動いたりしている。

## 18.2 提案

**教師の分割をCATIAのエッジ分割に置き換え、接合の種別を表現に載せる。**
形状ルールは書かない — CATIAが既に下した分割の決定を、そのまま学習対象にする。

| # | 変更 | 内容 |
|---|---|---|
| 1 | `convert.py` の再帰フィット廃止(外形) | **B-repエッジ1本 = プリミティブ1本**。頂点はCATIAの頂点。種別はそのエッジ単体への当てはめ(分割の曖昧さが無いので許容差論争が消える)。当てはめ残差はエッジ単位で記録し、残差が大きいエッジ(スプライン)は当面ARCで近似して残差を報告 |
| 2 | 接合チャンネルの追加 | スロットごとに1ch: **前の辺との接合が接線連続(G1)か、角(G0)か**。教師値は生polylineの接線角(<3°)から。分類ではなく連続性という幾何量 |
| 3 | 実現時のG1強制 | `realize_frame` で、G1フラグの立つ接合は**接線が一致するように構造で保証**(弧の膨らみ・角位置を接合条件から解く)。「揺れても偽の角にならない」を表現で保証 — 哲学1の適用 |
| 4 | 評価への追加 | 層2に「接合種別の一致率」(G1をG0にした/逆)を追加。**真の角(7%)を正しい場所に置けたか**が簡潔性の中身になる |

期待する効果:
- 長辺の途中の角はG1接合として生成され、実現時に滑らかに繋がる → **余剰回転の+30°が構造的に消える**
- 座面の2弧分割・折りの1弧といった**CATIAの合理性**がそのまま目標になる
- is_arc のラベル雑音問題(KB 16.2)は、分割が固定されることで大幅に軽くなる

## 18.3 検証(1・2は測定済み — 提案の成立条件は満たされている)

1. ✅ **エッジ単位の当てはめ残差**(60部品、1084エッジ): **全エッジが1本のLINEまたはARCに
   残差ほぼ0で当たる**(0.25t超え 0.0%。ARC 511 / LINE 573)。スプラインも再分割も不要 —
   **CATIAのエッジは最初からプリミティブ1本**であり、0.35mm許容差の再帰フィットは
   「既に切れているものを別の場所で切り直していた」ことになる
2. ✅ **容量**: エッジ数 中央値16・最大24 < EDGE_SLOTS 32
3. 新教師で `frame_rel` と同条件で再学習 → **KB 17の3層評価+接合一致率**で比較(拘束+ランクは共通)
4. 画像は3D斜め視点(`rational_3d.png` と同形式)

## 18.4 リスクと備え

- **座標量子化**: `parts` の bin 量子化(±0.3mm)は接線を壊す。接合チャンネルの教師値は
  量子化前の生polylineから計算して持ち込む(量子化後から再計算しない)
- CATIAの分割が部品作成手順に依存して揺れる可能性 → 同一形状の別バッチで分割の再現性を測る
- G1強制の解が過拘束になるケース(両隣ともG1の短い辺) → 最小二乗で解き、残差を層1に計上
