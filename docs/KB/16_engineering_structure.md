# 16. 目標の再定義 — 誤差ではなく「工学的に理にかなった構造」

Date: 2026-08-31
前提: KB 15 の施策 A/B/C と関係損失の結果(すべて実測済み)。

---

## 16.0 結論

**微細指標(is_arc 一致・弧の向き)を追うのをやめる。**それらは教師側の**当てはめ許容差(0.35mm)の産物**であり、
工学的な構造ではない。代わりに **B-rep/メッシュが要求する妥当性**を直接定義し、教師側の分解を
**設計意図に沿った正準形**に直し、中期的には**展開図(2D)で生成して折る**表現へ移す。

| 順 | 施策 | 訓練 | 狙い |
|---|---|---|---|
| 1 | **工学的妥当性の指標を定義**し、教師の値を床にして測る | 不要 | 何を目指すかを数値にする |
| 2 | **教師の正準化**: G1連続な隣接プリミティブを統合、許容差を板厚基準に | 不要(再学習は要) | ラベル雑音を消し、is_arc を学習可能にする |
| 3 | **展開図表現**: 2Dで外形+曲げ線を生成し、決定論的に折って3Dへ | 生成器の再設計 | 平面性・可展性・真の円弧を**構造で**保証 |
| 4 | 関係アテンションは維持(唯一微細指標を動かした)。正準教師で再学習 | 生成器 | |
| 5 | Kaggle の容量/学習長掃引は再投入(入力コピーを除去) | — | 過小適合の解消 |

## 16.2 is_arc は工学的な構造ではない — 教師側の証拠

| 実測 | 値 |
|---|---|
| 抽出元の外形辺で曲線(3点以上) | 87% |
| `convert.py` が ARC と判定 | 49% — 残りは **弦から 0.35mm 以内**で LINE |
| 曲線辺のうち弦から 0.35mm 以内 | **60%** |
| 真の弧のサジッタ | **中央値 0.64mm**、p90 3.32mm |
| 隣接辺と接線連続(5°以内)の弧 | **15%** |
| 連続する弧が中心を共有 | 29% |

**半数の「弧」はサジッタ 0.64mm 以下** — 15mm の辺に対して 4%。LINE か ARC かは 0.35mm の
許容差のどちら側に落ちたかで決まっており、**締結点から予測できる情報ではない**。
判定器の直接当てはめでも is_arc は AUC 0.60 だった。**ラベルが雑音だから**である。

同じ理由で「弧の向きが23%逆」も、サジッタ 0.6mm の弧の向きが逆でも**工学的には何も壊れない**
(Chamfer が 0.03mm しか動かないのはそのため)。

**さらに深い問題**: 3D の外形は曲げ部を横切る際に空間曲線になる。抽出器はそれをプリミティブ列に
分解するが、その分解は**設計意図ではなく B-rep の面分割の帰結**。接線連続が15%しかないのは、
「フィレット」ではなく「曲面上の辺の分割片」を弧と呼んでいるから。

> **教師の LINE/ARC 分解は設計意図ではない。それに一致させることは、工学的妥当性ではない。**

## 16.3 工学的妥当性を直接定義する(施策1)

B-rep / メッシュ生成が実際に要求するものだけを指標にする。**すべて教師にも適用し、教師の値を床にする。**

| 要求 | 指標 | 現状 |
|---|---|---|
| 閉じている | 端点 0 | ✓ 構造的に保証 |
| 交差しない | 自己交差 0% | ✓ 0%(教師も0%) |
| **スライバーが無い** | 辺長 < 板厚 t の辺の割合 | 未測定 |
| **接合部が曖昧でない** | 折れ角が「接線(<3°)」か「明確な角(>15°)」のどちらか。**3〜15°の中間帯の割合** | 未測定。中間帯はメッシュで潰れた要素を生む |
| **座面が収まる** | 各締結点の必要座面(φ36)が外形の内側に、余裕付きで入るか | 未測定。部品2の絵では外形が締結点に迫っている |
| 曲げ半径が製造可能 | R/t ≥ 2 | 教師 99.5%(KB 13) |
| 平面性 | パネルのねじれ | 0.067mm(λ=0 では 0.35mm) |
| 可展性 | 折り線間のパネルが平面/円筒 | 未測定(生成側) |

これらは**手設計の特徴をモデルに入れる**のではなく、**評価と選択(K個からの再ランク)に使う工学要件**。
チェックポイントに合わせた定数ではないので、KB 05.17 の寿命問題は起きない。

**最初にやること**: この表を教師と `frame_rel` の生成で埋める。**どこが実際に壊れているか**を、
Chamfer でも is_arc でもなく、この表で決める。

## 16.4 教師の正準化(施策2)

目標を「抽出器の分解」から「最小のプリミティブ分解」に置き換える。

1. 隣接する辺が **G1 連続**(折れ角 < ε)かつ同一プリミティブに乗る(共線 / 同心同半径)なら**統合**
2. 当てはめ許容差を **板厚基準**(例 0.25t)にし、0.35mm 固定をやめる
3. 統合後の分解で、is_arc の**エントロピー**と**辺数**がどれだけ下がるかを測る

期待: 辺数が減り(18→?)、残った弧は**サジッタが板厚以上の、工学的に意味のある弧**だけになる。
その状態なら is_arc は締結条件から予測可能な量になりうる。

**本数も分類も先に決めない。**統合は幾何(連続性)だけで行い、結果の本数は観測値。

## 16.5 展開図表現(施策3)— B-rep へ向けた本命

板金 CAD は **展開図 + 曲げ表(位置・角度・半径)** で部品を定義する。生成もそこで行えば:

| 性質 | 3D で生成 | 2D 展開図で生成 |
|---|---|---|
| 外形の平面性 | 学習(ねじれ 0.35mm) | **構造的に保証** |
| 弧が真の平面円弧 | 学習(空間曲線の分解片) | **構造的に保証** |
| 曲げ線が直線 | 学習(ジグザグ 34°/step) | **構造的に保証**(円筒曲げ) |
| 可展性 | 未保証 | **構造的に保証** |
| 締結点との整合 | 条件付け | 折り演算後に 3D で検証(**決定論的**) |

生成器は「2D 外形 + 2D 曲げ線 + 各曲げの角度/半径」を出し、**折り演算(決定論的)**で 3D にする。
締結点(3D 入力)は、折った結果がそこに来るように学習させる — 折り演算は微分可能に書ける。

**曲げ線も 2D では直線**なので、count-free トークン表現のジグザグ問題が構造的に消える。
ビード等の非可展特徴は展開図上の**押し出し特徴**として別枠(CAD と同じ)。

**先に測ること(訓練不要)**:
- サイドカーの `panels` / `folds` を使って教師の外形を**厳密に展開**し、2D での辺数・is_arc・接線連続率を 3D と比較する。
  2D で分解が単純化する(接線連続が上がる、辺数が減る)なら、この方向は正しい。
- 展開→折りの往復誤差(構造の損失が無いことの確認)。

**リスク**: 締結点は 3D 入力なので、生成器が「折った後の位置」を逆算する必要がある。
これは今の 3D 直接生成より難しい可能性がある。→ 折り演算を微分可能にし、3D での締結点整合を
損失に入れる(これは「導出できない入力との整合」なので KB 12 に抵触しない)。

## 16.6 やめること・続けること

| やめる | 理由 |
|---|---|
| is_arc 一致率・弧の向きを目標にする | 許容差の産物(16.2) |
| 局所判定器で is_arc / 膨らみを判定させる | 局所に情報が無い(AUC 0.56 / 0.50) |
| 関係損失(現行の実装) | 長い辺に集中。正規化版は未検証のまま保留 |

| 続ける | 理由 |
|---|---|
| 関係アテンション | 唯一の正の結果 |
| 中央選択 K=9 → 16.3 の妥当性で再ランク | 選択の余地は実在(オラクル) |
| 設計スペック条件 | 導出不能な情報の唯一の例外 |
| Kaggle 容量/学習長掃引 | 過小適合(訓練 9.03 > 検証 7.44mm)は未解決 |

Kaggle 失敗の原因: ランチャーが入力を `/kaggle/working/repo` に丸ごとコピーした(出力容量/パス)。
**入力パスを直接参照する形に直して再投入。**
