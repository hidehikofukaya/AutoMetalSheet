# 1. 課題とデータ

## 1.1 やろうとしていること

**締結点2点のみを入力に、板金部品の中立面ワイヤーフレームを生成する。**

決定的な制約: **形状ルールを一切書かない。**「板金だから曲げ半径はこう」といった
決定論的な規則は入れず、すべて学習で獲得する。

出力の最終形はワイヤーフレーム — 頂点と、それを結ぶ辺(直線/円弧)。CAD が消費できる形。

## 1.2 入力に何が入っているか(検証済み)

モデルに届くのは**締結点由来の情報だけ**。2通りで確認した。

| 検証 | 結果 |
|---|---|
| 部品を FIX 頂点だけに剥ぎ取る(辺も他の頂点も全削除)→ 条件行 | **12/12 ビット一致** |
| 同上 → アンカー行 | **12/12 ビット一致** |
| `check_no_envelope_leak`(締結点を mm 位置に保ち別の境界箱へ再量子化) | **PASS**(最悪ずれ 0.020mm = 再量子化ノイズ) |
| 外形フレームモデルの文脈エンコーダ重み | **0個**(点群を入れる経路が存在しない) |

具体的な中身:

```
cond (4行 x 8ch)  締結点の位置3・軸3・有効フラグ、最終行に log(締結点間距離)/10
fix  (16行 x 6ch) ガード円板: 締結点と軸だけから合成した phi20 の円板上の点と法線
```

**ガード円板は教師ではない。**ボルトには軸に垂直な平座面が要る、という物理から
締結点と軸だけで合成している。実データとの一致は 240 サイトで 95 パーセンタイル
0.00mm、傾き 0.0°(半径 10mm の場合。15mm では傾き 49° になるので 10mm が正直な限界)。

### 過去のリーク事故

2026-08-27 まで、**全モデルが教師の正解 bbox を座標系に使っていた**。部品の位置・
向き・寸法をそのまま渡していたことになる。締結点フレームへ移行し、
`check_no_envelope_leak` を回帰テストとして常設した。
→ [[05_measurement_pitfalls]]

## 1.3 締結点フレーム

```
原点  2つの締結点の中点
単位  締結点間の距離(部品対角/この距離 = 1.21〜1.69 なので座標は ±0.85 前後)
e1    締結点から締結点への方向
e2    e1 から最も離れた締結軸を直交化(全部品で 17.5° 以上。退化しない)
```

**重要**: フレーム座標は締結点間距離で正規化されている。
**生の 0.039 は 0.039mm ではない。**100mm の締結間隔なら 3.9mm。
この取り違えで一度誤った合否判定を出した。→ [[05_measurement_pitfalls]]

### 辺の構造(実測、2300部品)

| | 中央値 | p90 | 最大 |
|---|---|---|---|
| 全頂点 | 111 | 125 | 170 |
| 全辺 | 87 | 98 | 138 |
| **外形の辺** | **18** | 21 | 26 |
| **外形の頂点** | **26** | 35 | 43 |

**辺の型は2種類だけ。スプラインは1本もない。**

| 型 | 参照点 | 外形 | 曲げ線 |
|---|---|---|---|
| LINE | 2(始点・終点) | 48.3% | 84.1% |
| ARC | 3(始点・**中点**・終点) | 51.7% | 15.8% |
| CIRCLE | 3 | — | 0.1% |

ARC は3点を通る円として実現される(`codec.realize_edge`)。

**外形は 2300/2300 部品で厳密に1つの閉ループ。**これが表現設計の土台になっている。

### 曲げ線クラスの罠

`bend_line` は1部品あたり **68セグメント、長さ中央値 6mm** あるが、**68本の折りではない**。
このクラスは**円筒面と平面が接する線**を印付けるので、**1つの折りが2本を生む**
(二面角0°、間隔は曲げ半径ぶん = 中央値 5.5mm)。さらに 61% は 10mm 未満で、
全長の 11.9% しか持たないテッセレーションの破片。

10mm 未満を切ると 24本、被覆の損失 0.42mm。さらに平行な対を統合すると **15本**
(p90 19、最大 24)。**設計上の「折り」に対応するのは統合後の数。**

### 平面構造

| | 教師 | 
|---|---|
| 部品あたりの相異なる辺法線 | 中央値 **3**、p90 6、最大 10 |
| どの平面にも乗らない角 | **0%** |
| 角→平面の残差 | **0.16mm**(= 量子化ノイズ) |
| **締結点の軸 vs 最寄り辺の法線** | **中央値 0.0°、100% が15°以内** |
| 両締結点を含む単一平面 | **存在しない**(最良でも 13.35mm 離れる) |

最後の2行が重要。**各締結点は個別にパネル上に乗るが、2点は別々のパネルにある。**
ブラケットとして当然の構造。

## 1.5 情報限界 — これが評価の前提

**締結条件がほぼ同一の部品どうしが 14.9mm 違う。**

したがって:

- **教師との距離を合格条件にしてはいけない。**どれだけ良いモデルでもこれ以下には
  ならない。
- **絶対 mm の閾値は置けない。**「意味のある距離」は部品の性質であってモデルの
  性質ではない。判定は相対値か、物理的妥当性で行う。

サンプリングの揺らぎも無視できない。**形状誤差の数値には ±0.2mm 程度の抽出ノイズ**
があり、1回の抽出で選んだ設定は選んだことにならない。→ [[05_measurement_pitfalls]]

## 1.6 部品数を増やす効果

**500 → 1000 部品は効いた**(第1段: 1000部品は epoch 50 で端点 2.3%、500部品は
epoch 95 で 10.3%)。ただし当時「500 と 1000 で差がない」と測定した記録があるが、
**それは根本的に壊れたモデル上での測定なので無効**。

**現在の外形フレーム生成器ではデータ増は効かない。**過学習がゼロで、訓練誤差
(9.03mm)が検証誤差(7.44mm)より大きい。→ [[06_status_and_numbers]]
