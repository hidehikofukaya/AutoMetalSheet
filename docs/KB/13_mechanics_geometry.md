# 13. 材料力学 × 幾何 — 何を教師として絞り取れるか

Date: 2026-08-31
目的: CATIA データから、曲げ線・外形線・凹凸構造を特定するための情報を最大限引き出す。
制約: **KB 12 の法則** — 既に持っている情報から導出できるものを条件に足しても効かない。
したがって候補は必ず **(a) 抽出可能か (b) 導出可能でないか (c) 実際に情報を持つか** の
3点で分類する。

---

## 13.0 結論を先に

| 使い方 | 何を | 根拠 |
|---|---|---|
| **入力(条件)** | 板厚、曲げ半径の下限、プレス方向、相手部品 | 締結点から導出できない |
| **教師信号(補助損失)** | 可展性、展開図、曲率場 | 導出できるので入力にはならないが、**教師にはなる** |
| **検証** | 可展性、面積保存、曲げ半径の下限、自己交差 | 物理的に必須で、教師の値が床になる |
| **表現の構造** | 可展性を満たす表現(ルーリング) | 「性質は表現に埋め込め」 |

**入力に足せるものは実は少ない。**大半は「導出できる」側にあり、KB 12 が適用される。
ただし**教師信号としては全部使える** — これが今回の主要な発見。

---

## 13.1 板金の中立面は可展面である — 最強の幾何拘束

### 学術的事実

板金は平板を**等長変形**(曲げ・巻き)で作る。等長変形は **Gauss の驚異の定理**により
**Gauss曲率 K を保存する**ので、平板(K=0)から作られる中立面は**至るところ K=0**。

帰結:
- 主曲率の一方が常にゼロ(κ₁·κ₂ = 0)
- ゼロでない主曲率の方向に垂直な**直線(ruling)**が面上を走る
- 面は「無限に密に並んだ直線の族」として構成される
  ([Wolfram MathWorld](https://mathworld.wolfram.com/DevelopableSurface.html))

**曲げ線とは、κ_max が 0 から非ゼロへ遷移する境界**である。分類ではなく、場の性質。

### 現在の抽出との対応

抽出器の `face_geo` が既にこれを分類している:

```
face_geo: ['single_curved', 'double_curved', 'planar', ...]
```

- `planar` — κ₁=κ₂=0
- `single_curved` — 円筒。κ₁≠0, κ₂=0(**可展**)
- `double_curved` — 球・自由曲面。**可展でない**

**注意: 実データには `double_curved` が存在する。**ビードの四隅の球パッチなどで、
厳密には可展でない(伸びを伴う成形)。「板金は全て可展」は近似である。

### 実測(30部品、曲げ線からの距離4mm以内を正例とした AUC)

| 量 | AUC |
|---|---|
| 法線回転率 \|grad n\| | 0.885 |
| 最大主曲率 \|κ_max\| | **0.895** |
| \|Gauss曲率\| | 0.896 |
| 外形からの距離 | 0.444(**無意味**) |

> **Gauss曲率の0.896は数値的な人工物。**可展面では厳密にゼロのはずで、κ_max が大きい
> 箇所で二次当てはめの残差が増え、それを拾っているだけ。**この数字を根拠にしてはいけない。**

**採用すべきは κ_max。**可展面では κ_max が曲げの強さそのものを表す。

### 関連研究

- 可展面のセグメンテーションを**法線の不連続を疎に検出**する問題として定式化
  ([Mathematics 2026, 14(5), 757](https://doi.org/10.3390/math14050757))
- ruling を制御点から生成する B-spline 可展面
  ([arXiv:2004.09038](https://arxiv.org/pdf/2004.09038))
- 有理・NURBS 可展面の CAD における特徴づけ
  ([arXiv:2003.00792](https://arxiv.org/pdf/2003.00792))

## 13.2 展開図(flat pattern)— 同じ部品の別の見方

### 学術的事実

可展面は**等長に平面へ展開できる**。展開図は板金の実際の製造入力(ブランク形状)で、
3D形状と1対1に対応する。

展開すると:
- **曲げ線は直線になる**(円筒の ruling が平行線に写る)
- **外形は平面上の閉曲線になる**
- **面積と曲線長が保存される**

**これは「導出できるが別表現」という珍しい位置にある。**3D形状から計算できるので
KB 12 により入力にはならないが、**補助的な教師信号**としては別の勾配を与える。

### なぜ有望か

現在の生成器の失敗は「512個の変位を積分して形が壊れる」という**大域的な整合の問題**。
展開図は**大域的な拘束**(面積保存、長さ保存)を1つの量に凝縮する。

例えば「生成した曲げ線と外形から展開図を作り、その面積が教師と一致するか」は、
局所的な誤差では動かず、大域的な破綻でだけ動く。

### 関連研究

- エネルギー最小化による板金の展開
  ([ResearchGate](https://www.researchgate.net/publication/257337731_An_energy-based_surface_flattening_method_for_flat_pattern_development_of_sheet_metal_components))
- 展開手法の設計上の考慮
  ([J. Intell. Manuf. 2014](https://link.springer.com/article/10.1007/s10845-012-0679-9))
- **Flatten Anything** — 教師なしの神経曲面パラメータ化。Deform-Net / Wrap-Net /
  Cut-Net / Unwrap-Net の4つで双方向の写像を学ぶ
  ([arXiv:2405.14633](https://arxiv.org/pdf/2405.14633))
- **Flattening-Net** — 不規則な3D点群を規則的な2D幾何画像として表現
  ([IEEE TPAMI 2023](https://dlnext.acm.org/doi/10.1109/TPAMI.2023.3244828))

## 13.3 剛性 — なぜビードとリブが存在するか

### 学術的事実

薄板は面外曲げに弱い。ビード・リブ・フランジは**断面二次モーメント I を上げる**ために
入れる。矩形断面では I = bh³/12 なので、**高さ h の3乗**で効く。板厚を増やすより
形状を変えるほうが、質量あたりの剛性が桁違いに大きい。

**したがってビードの位置と向きは、剛性が必要な方向で決まる。**設計意図そのもの。

### 実測(本プロジェクト)

断面二次モーメントを入力に加えた場合の曖昧さの縮小:

| 与える情報 | 最も似た部品どうしの形状差 |
|---|---|
| 締結点のみ | 6.36mm |
| 締結点 + **断面二次モーメント** | **5.69mm(11%改善)** |
| 断面二次モーメントのみ | 7.50mm |

**11%は実在するが小さい。**そして代償として、テンソルは部品の向きと寸法を含むので、
以前除去した包絡リークと同じものを再導入することになる。

### 関連研究

- 荷重経路解析に基づく骨格構造の生体模倣設計。**断面の面積と慣性モーメントを最大化**する
  初期化で剛性 +62.3%、重量 −24.75%
  ([Appl. Sci. 2020, 10(22), 8251](https://doi.org/10.3390/app10228251))
- トポロジー最適化結果の中立面を**表面スケルトン**で再構成
  ([Proc. Design Society](https://www.cambridge.org/core/journals/proceedings-of-the-design-society/article/subdivision-surface-midsurface-reconstruction-of-topology-optimization-results-and-thinwalled-shapes-using-surface-skeletons/1E82A1D71A4DAF9B297269EE4BDBCF9B))
- 中立軸スケルトンによるトポロジー最適化構造の自動再構成
  ([Springer 2021](https://link.springer.com/chapter/10.1007/978-3-662-63143-0_3))

## 13.4 荷重経路 — 締結点から形が決まる唯一の物理的経路

### 学術的事実

部品は締結点間で荷重を伝える。**荷重経路**(load path)は、応力の主方向に沿った
流れとして定義され、トポロジー最適化ではこれが構造の骨格になる。

**これが本課題で最も筋の良い物理的事前分布**である理由:
- 入力(締結点)から**直接計算できる**
- 形状が未知でも、**荷重経路の候補**は境界条件だけから絞れる
- ビード・リブは荷重経路に沿って、または直交して置かれる

### 位置づけ

**ただし KB 12 が効く。**荷重経路は締結点から計算できるので、**モデルは既に知っている**
可能性が高い。効くとすれば「モデルが自力で計算するには深すぎる」場合だけ。

**測ってから判断すべき。**曲率場は「導出できる」側で30%悪化した前例がある。

### 関連研究

- 荷重経路解析による骨格設計(上記 Appl. Sci. 2020)
- 薄肉構造のトポロジー最適化と適応メッシュ
  ([arXiv:1908.10825](https://arxiv.org/pdf/1908.10825))
- 埋め込み固体 MMC による複雑薄肉構造の陽的設計
  ([arXiv:2306.10449](https://arxiv.org/pdf/2306.10449))

## 13.5 成形限界 — 何が作れないかの拘束

### 学術的事実

| 拘束 | 内容 |
|---|---|
| **最小曲げ半径** | 材料と板厚で決まる。R/t が下限を割ると外側が破断 |
| **スプリングバック** | 弾性回復。曲げ角は狙いより開く。R/t と降伏比で決まる |
| **成形限界線図(FLD)** | 主ひずみ空間での破断限界。伸びフランジ・張出しの可否 |
| **中立軸のシフト(K因子)** | 展開長 = 内R + K·t。K は 0.3〜0.5 |

### 本データでの実測

| | 値 |
|---|---|
| 曲げ半径 | 10.0〜22.5mm(中央値14.2) |
| 板厚 | サイドカーの `thickness_mm` にある |
| 曲げ角 | 0.5〜134.6°(中央値37.8) |

**R/t は計算可能。**「生成された曲げが製造可能か」の検証に直接使える。
**教師との距離が使えない本課題で、絶対的な合否条件になりうる数少ない量。**

## 13.6 抽出済みなのに使っていない情報

`runs/wtok_synth/wireframes/*.json` に既にあり、**変換器が捨てているもの**:

| フィールド | 内容 | 使えるか |
|---|---|---|
| `face_geo` | `planar` / `single_curved` / `double_curved` | **可展性の正解ラベル。有望** |
| `face_radius_mm` | 各面の半径 | **曲げ半径の正解。R/t 検証に直結** |
| `face_types` | `plane`/`cylinder`/`sphere`/`freeform`/`cone` | 面の分類 |
| `face_wall` | 壁面かどうか | フランジ・ビード壁の識別 |
| `dihedral_deg` | 辺での二面角 | **実測すると中央値0.0°で使えない**(§13.7) |
| `length_mm` | 辺の長さ | 自前で計算済み |
| `closed` | 辺が閉じているか | 連結処理で使える |
| `clusters` | `{'kind': 'bend', 'n_faces': 89}` | **曲げ領域のまとまり。未検証** |
| `n_planar_faces` / `n_wall_faces` | 面数の内訳 | 部品の複雑さの指標 |

**`face_geo` と `face_radius_mm` が最も有望。**可展性と曲げ半径という、
材料力学的に意味のある2量の正解値が、既に抽出されている。

## 13.7 使えないと分かったもの

### `dihedral_deg` は中央値 0.0°

| 辺の型 | 中央値 | 範囲 |
|---|---|---|
| `bend_line` | **0.00°** | 0.0〜3.3 |
| `surface_frame` | 0.00° | 0.0〜2.4 |
| `seam` | 0.46° | 0.0〜2.2 |

**曲げ線の二面角はゼロ。**当然で、`bend_line` は円筒面と平面が**接する**線
(接線連続)を印付けているため。二面角で曲げの強さは測れない。

### 外形からの距離は無意味(AUC 0.444)

偶然以下。曲げ線は外形との距離では特徴づけられない。

### Gauss曲率は数値的にゼロにならない

理論上ゼロだが、点群からの推定では κ_max に相関した残差が乗る。
**AUC 0.896 は信号ではなく人工物。**

## 13.9 本プロジェクトの原則との整合

> **性質は表現に埋め込め、損失に書くな**(4勝4敗)

可展性は**表現に埋め込める**性質である。ruling を明示的に持つ表現なら、
κ₁·κ₂=0 が構造的に保証される。これは順序付きリングが閉ループを保証したのと同じ形。

**ただし実データには `double_curved` が存在する**ので、可展性を厳密に強制すると
ビードの四隅が表現できなくなる。**「可展を優先し、必要なら破れる」表現が要る。**

> **導出できる情報を条件に足しても効かない**(4回失敗)

本節の候補の大半は導出可能側にある。**入力ではなく教師信号・検証として使うこと。**
これが今回の整理の主要な結論。
