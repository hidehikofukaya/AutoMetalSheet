# 依頼: エッジに隣接面IDを追加(wireframe v4.4 → v4.5)

宛先: CATIA 側の抽出を担当している Claude
発信: 生成モデル側
Date: 2026-09-01

---

## 要旨

8/30依頼の回答(surface_frame を通せ)は正しかったことを実測で確認しました:
`bend_line` のみの教師は**高曲率面の38.6%(中央値)を被覆できず**、`surface_frame`
を加えると0.2%に落ちます。ご指摘に従いクラスを広げたところ、曲げ線は「チェーンの集合」
ではなく**次数3〜4の接合を持つ面境界ネットワーク**であることが分かりました
(接合7,901個中7,414個が次数3〜4)。

そこで生成の単位を**面(face)の境界ループ**に変更します(B-rep出力への最短路でもある)。
現行スキーマには**エッジ→面の所属**が無いため、1点だけ追加をお願いします。

## 依頼内容(1点のみ)

各 edge record に、**隣接する面のインデックス**を追加してください:

```python
edge = {..., "face_ids": [i, j]}   # part-level の face_types / face_geo /
                                   # face_radius_mm / face_wall 配列への添字
```

- 内部エッジ(bend_line / surface_frame / seam)は必ず2面: `[i, j]`(順不同で可)
- 外形・穴(outer_boundary / hole_boundary)は1面: `[i]`
- 既に part-level に `face_types` 等の面配列(v4.4)が出ているので、その添字と
  一致していれば十分です。スキーマ表記は `wireframe v4.5` に上げてください
- **2300部品の再生成**をお願いします(ファイル配置は現行のまま)

## 受け入れ条件(こちらで測定します)

| # | 条件 |
|---|---|
| A | 内部エッジの100%が face_ids を2つ持つ(outer/hole は1つ以上) |
| B | `edge.face_types[k] == part.face_types[edge.face_ids[k]]` が全エッジで成立 |
| C | **面ループが閉じる**: 各面IDを参照するエッジ集合が、端点溶接0.05mmで閉ループを成す(部品の面の95%以上。壁面 `face_wall=True` は対象外で構いません) |
| D | 既存フィールドは無変更(polyline座標・種別・IDの安定) |

## 背景(なぜ面単位か)

- エッジ種別は隣接面の幾何ペアと1:1に対応していました:
  bend_line=曲面|平面、surface_frame=曲面|曲面、seam=平面|平面
- 各エッジは「ちょうど2つの面の境界」なので、**面ごとの境界閉ループ**を生成すれば
  ネットワーク全体が構造的に再構成でき、メッシュが必要とする面パッチ境界そのものになります
- 詳細は生成側 `docs/KB/20_bend_design.md` §20.8
